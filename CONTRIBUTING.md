# Вклад в проект (Contributing)

Спасибо, что решили помочь проекту! 🙌

---

## Как сообщить об ошибке

1. Проверьте [список issues](https://github.com/AntoGA/Ai-race/issues).
2. Создайте новый issue, указав версию, окружение, шаги воспроизведения и ожидаемое/фактическое поведение.

## Как предложить фичу

1. Создайте issue с описанием идеи.
2. Обсудите с мейнтейнерами до начала работы.

---

## Настройка окружения

```bash
git clone https://github.com/AntoGA/Ai-race.git
cd Ai-race
cp .env.example .env          # задайте свои пароли
docker compose up -d --build
```

### Локальная разработка без Docker

```bash
# Frontend
cd frontend
npm install
npm run dev                   # http://localhost:3000

# Backend (требует запущенные PostgreSQL и Redis)
cd backend
npm install
npm run dev                   # http://localhost:3001
```

## Работа с git

### Ветки

| Ветка | Назначение |
|---|---|
| `main` | Стабильная версия |
| `develop` | Интеграционная ветка |
| `feature/<название>` | Новая функциональность |
| `fix/<название>` | Исправление ошибки |
| `docs/<название>` | Документация |

### Conventional Commits

| Префикс | Назначение |
|---|---|
| `feat:` | Новая фича |
| `fix:` | Исправление бага |
| `docs:` | Документация |
| `refactor:` | Рефакторинг |
| `chore:` | Инфраструктура/зависимости |
| `test:` | Тесты |

---

## Оформление Pull Request

1. Один PR = одна задача.
2. Название — по Conventional Commits.
3. Убедитесь, что CI проходит.
4. В описании укажите связанные issues (`Closes #123`).

### Чек-лист перед PR

- [ ] Код собирается (`docker build` без ошибок)
- [ ] SQL-схема применяется к чистой БД
- [ ] Нет закоммиченных секретов (`.env`)
- [ ] Обновлена документация при изменении API
